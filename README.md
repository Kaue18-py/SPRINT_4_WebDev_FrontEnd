# JOVI Landing Page

Landing page moderna e responsiva desenvolvida para a marca JOVI, com foco em apresentação visual, experiência do usuário e conversão de leads. O projeto foi pensado para destacar a proposta da marca, comunicar valor de forma clara e criar uma identidade digital forte e profissional.

## 📌 Objetivo

A JOVI busca apresentar sua solução de forma atrativa e acessível, com uma interface elegante, moderna e otimizada para dispositivos móveis e desktop. A landing page foi desenvolvida para transmitir confiança, inovação e simplicidade, reforçando a presença digital da marca no mercado.

## ⚙️ Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## ✨ Funcionalidades esperadas

- Hero section com mensagem principal e chamada para ação
- Seções de apresentação da marca e proposta de valor
- Destaque de diferenciais e benefícios
- Layout responsivo e visual clean
- Interface moderna com utilização de Tailwind para design consistente
- Estrutura pronta para futuras integrações e expansão

## 🚀 Como executar o projeto

1. Clone o repositório
2. Acesse a pasta do projeto
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse a aplicação no navegador pela URL indicada no terminal
